# Personal Task Tracker

A beginner-friendly full-stack application for managing personal tasks.

## Planned Features

- Add a task
- View all tasks
- Mark a task as completed
- Delete a task

## Planned Technology Stack

- Frontend: React and TypeScript
- Backend: Node.js, Express, and TypeScript
- Database: SQLite
- Version Control: Git and GitHub
- Testing and Automation: Automated tests and GitHub Actions
- Containerization: Docker
